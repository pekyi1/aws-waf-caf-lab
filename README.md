# AWS WAF + CAF Assessment Lab Submission

## Overview
This repository contains my submission for the lab:
**“Design and Evaluate an AWS Solution Using the Well-Architected and Cloud Adoption Frameworks.”**

The work evaluates a two-tier web application migration (frontend + backend database) from on-premises to AWS using:
- AWS Well-Architected Framework (WAF)
- AWS Cloud Adoption Framework (CAF)

## Contents
- `aws_waf_caf_assessment.md`  
  Full lab report including:
  - Task 1: Architecture review (components + risks)
  - Task 2: WAF assessment table (5 pillars)
  - Task 3: CAF readiness summaries (6 perspectives)
  - Task 4: Improved AWS architecture description
  - Reflection (≈150 words)

- `diagram/architecture-diagram.png` (or `.drawio` / `.pdf`)  
  Improved architecture diagram (uploaded as an image or diagram file).

## Approach (How I Completed the Lab)
1. Identified key workload components and risks for a basic two-tier migration.
2. Evaluated strengths and gaps using the 5 WAF pillars and mapped improvements to AWS services.
3. Assessed organizational readiness using the 6 CAF perspectives and documented recommended enablers.
4. Proposed an improved AWS target architecture aligned to WAF and supported by CAF readiness actions.
5. Wrote a short reflection summarizing what was learned.
